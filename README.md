# Cricket Player Landing Page

A modern and responsive landing page designed for a professional cricket player. The website presents the player's profile, achievements, career highlights, and other important information in a clean and attractive interface.

## Features

- Responsive landing page design
- Navigation bar with smooth scrolling
- Hero section with player name and image
- About section with player information
- Career achievements and highlights
- Interactive hover effects
- Clean and user-friendly interface
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

# Temperature Converter 🌡️

A simple and user-friendly **Temperature Converter** web application that allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin**.

## Features

* 🌡️ Convert between Celsius, Fahrenheit, and Kelvin
* ⚡ Instant temperature conversion
* 🎨 Clean and simple user interface
* 📱 Responsive design
* ❌ Handles invalid input

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

Enter a temperature value, select the input and output units, and the application calculates and displays the converted temperature instantly.

## Purpose

This project was created to practice **HTML, CSS, and JavaScript**, especially user input handling, mathematical calculations, and DOM manipulation.
